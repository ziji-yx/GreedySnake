# 贪吃蛇（Greedy Snake）

一个使用 C 语言编写的 Windows 控制台贪吃蛇小游戏。项目不依赖第三方库，包含完整的菜单、五档难度、动态陷阱、暂停、排行榜、历史记录和自动测试。

## 功能

- WASD 与方向键双套操作方式
- 五档移动速度，难度越高节奏越快
- 完整的墙体、自身碰撞和反向移动判定
- 蛇变长后逐步生成随机陷阱，数量随长度提升并设有上限
- 食物只会生成在空白位置，不会与蛇身重叠
- 支持暂停、返回主菜单、通关判定
- 游戏结束后保存玩家名、得分、难度和时间
- 按分数展示排行榜，同时保留最近 15 局历史记录
- 自动读取旧版 `record.txt` 格式，原有记录不会丢失
- 内置 `--self-test`，可在不进入游戏的情况下验证核心规则

## 快速开始

环境要求：

- Windows 10 或 Windows 11
- GCC / MinGW-w64
- 终端窗口至少 80 列、28 行（推荐 Windows Terminal）

直接编译：

```powershell
gcc -std=c11 -O2 -Wall -Wextra -Wpedantic snake.c user.c win.c -o snake.exe
```

运行：

```powershell
.\snake.exe
```

如果使用 Make：

```powershell
mingw32-make build
mingw32-make run
```

## 操作方式

| 按键 | 功能 |
| --- | --- |
| `W` `A` `S` `D` | 向上、向左、向下、向右移动 |
| 方向键 | 与 WASD 相同 |
| `P` / 空格 / `Esc` | 暂停或继续 |
| `Q` | 退出当前局并返回主菜单，本局不保存 |

蛇不能直接反向移动。为了避免连续快速按键导致意外反向，每次移动前只接受第一个有效方向输入。

## 难度

| 等级 | 名称 | 移动间隔 |
| --- | --- | --- |
| 1 | 悠闲 | 220 ms / 格 |
| 2 | 轻松 | 150 ms / 格 |
| 3 | 标准 | 100 ms / 格 |
| 4 | 挑战 | 65 ms / 格 |
| 5 | 极限 | 40 ms / 格 |

每吃到一个食物获得 10 分，蛇身增加 1 节。所有难度使用相同计分规则，排行榜在同分时优先展示更高难度，再按时间排序。

## 陷阱机制

陷阱使用紫色 `X` 表示，生成后永久保留。

| 蛇身长度 | 陷阱数量 |
| --- | --- |
| 3 - 9 | 0 |
| 10 - 12 | 1 |
| 13 - 15 | 2 |
| 16 - 18 | 3 |
| 每增加 3 节 | 再增加 1 个 |
| 43 及以上 | 12（上限） |

陷阱不会生成在蛇身、食物或已有陷阱上，并且与蛇头的曼哈顿距离至少为 3 格，避免升级时立刻无解。蛇头撞到陷阱会立即结束本局。

## 记录文件

游戏数据保存在当前工作目录的 `record.txt` 中。新格式为：

```text
玩家名|得分|难度编号|结束时间
```

例如：

```text
Player|120|3|2026-10-19 14:30:00
```

旧版记录格式仍可读取。若文件不存在，游戏会自动将其视为空排行榜；若保存失败，请检查目录写入权限。

## 测试

编译后运行内置规则测试：

```powershell
.\snake.exe --self-test
```

测试覆盖初始化、食物安全性、反向限制、墙体碰撞、自身碰撞、蛇尾让位、陷阱触发阈值、陷阱数量增长与上限、陷阱碰撞、吃到食物后的增长、计分和食物重新生成。

## 项目结构

```text
GreedySnake.demo/
├── snake.c       # 主菜单、游戏循环、碰撞逻辑、渲染和自测
├── snake.h       # 共享数据结构与游戏接口
├── user.c        # 记录文件读写、排行榜和历史记录展示
├── user.h        # 记录模块接口
├── win.c         # Windows 控制台光标、颜色和中文输出
├── win.h         # 控制台模块接口
├── Makefile      # 构建、运行、测试和清理命令
├── record.txt    # 本地成绩记录
└── snake.exe     # 可执行文件
```

## 构建与清理

```powershell
mingw32-make build
mingw32-make test
mingw32-make clean
```

如果没有 `mingw32-make`，可直接使用上文的一行 `gcc` 命令。

## 常见问题

**中文显示异常**

项目使用 UTF-8 源码和输出，并会将控制台代码页切换为 UTF-8。建议在 Windows Terminal 中运行；旧版控制台如出现字体缺字，可更换为支持中文的等宽字体。

**排行榜没有新记录**

游戏结束后需要输入 `y` 才会保存。按 `Q` 主动退出当前局不会写入记录。记录文件位于启动程序时的当前工作目录。

**方向键没有反应**

方向键和 WASD 均可使用。终端窗口需要保持焦点；如果输入法处于中文候选状态，先切换到英文输入。
